# FORMA Studio

A browser-based parametric 3D configurator for interactive curve editing, precision solid generation, and manufacturing-oriented STL export.

## Project status

In active development for a three-day engineering assessment. Functional claims and print readiness will be validated before release.

## Planned stack

React, TypeScript, Vite, Three.js, React Three Fiber, SVG, and Vitest.

## Development workflow

- `main`: stable integration branch
- `feature/project-setup`: application scaffold and tooling
- Subsequent branches: curve editor, geometry engine, preview, printable export, quality and delivery

## Core objectives

- Editable 2D profiles with control points
- Live 3D geometry generated from parametric profiles
- Precisely dimensioned cavities, fittings, and base
- Validated, separate STL exports for printable components

The project will distinguish preview meshes from print-validated solids and will not claim production manufacturing accuracy without verification.
